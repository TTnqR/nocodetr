BUBBLE.IO · API REHBERİ

Bubble'da Twitter/X API'sine nasıl bağlanılır? OAuth 2.0 adım adım kurulum

AY
Ahmet Yılmaz
14 Ocak 2025 12 dk okuma 3.248 görüntülenme Orta Seviye
İçindekiler
  1. Twitter Developer Portal'da uygulama oluşturma
  2. Bubble API Connector kurulumu
  3. OAuth 2.0 token akışını yapılandırma
  4. "401 Unauthorized" hatasını giderme
  5. Rate limit yönetimi ve counter kurulumu

Twitter/X, API erişim modelini 2023'te köklü biçimde değiştirdi. Ücretsiz tier artık yalnızca yazma izni içeriyor; okuma ve arama işlemleri için Basic tier ($100/ay) gerekiyor. Bu rehberde Basic tier ile Bubble'da güvenli OAuth 2.0 bağlantısı kurmanın adımlarını göreceğiz.

1. Twitter Developer Portal'da Uygulama Oluşturma

developer.twitter.com adresine git ve yeni bir proje oluştur. App Type olarak Web App, Automated App or Bot seç. Bu seçim, OAuth 2.0 PKCE akışını etkinleştirir.

⚠️ Sık Yapılan Hata #1: Callback URL kısmına Bubble uygulamanın URL'ini eklerken trailing slash eklemeyin. Doğru format: https://seninsiten.bubbleapps.io/api/1.1/oauth_redirect — sonda / olmamalı.

Developer Portal'da Keys and Tokens bölümünden Client ID ve Client Secret değerlerini kopyalayıp güvenli bir yere kaydet. Bu değerler bir kez gösterilir.

2. Bubble API Connector Kurulumu

Bubble editöründe Plugins → + Add Plugins yolunu izle ve API Connector'ı yükle. Yeni bir API ekle, isim olarak "Twitter API v2" kullan. Authentication kısmında OAuth2 User-Agent Flow'u seç.

// API Connector OAuth2 Ayarları
App name:          Twitter API v2
Authentication:    OAuth2 User-Agent Flow
Authorization URL: https://twitter.com/i/oauth2/authorize
Token URL:         https://api.twitter.com/2/oauth2/token
Client ID:         [Developer Portal'dan al]
Client secret:     [Developer Portal'dan al]
Scope:             tweet.read users.read offline.access
✓ İpucu: offline.access scope'unu mutlaka ekle. Bu olmadan refresh token alınmaz ve kullanıcı her seferinde yeniden giriş yapmak zorunda kalır.

3. OAuth 2.0 Token Akışını Yapılandırma

API Connector'da ilk API call'u oluştur: GET https://api.twitter.com/2/users/me endpoint'ini ekle. Use as kısmında Action seç. Initialize the call butonuna tıkla ve tarayıcıda açılan pencerede Twitter hesabınla yetkilendir.

4. "401 Unauthorized" Hatasını Giderme

Bu hata genellikle iki nedenden kaynaklanır: Bearer Token yerine User Access Token beklenmesi veya scope yetersizliği.

// App-only endpoint için (tweet arama vb.)
Header: Authorization: Bearer APP_BEARER_TOKEN

// User endpoint için (kullanıcı adına tweet atma vb.)
Header: Authorization: Bearer USER_ACCESS_TOKEN
Reklam Alanı

5. Rate Limit Yönetimi ve Counter Kurulumu

Twitter Basic tier'da aylık 10.000 tweet okuma hakkın var. Bunu takip etmek için Bubble veritabanında bir counter oluşturmalısın.

Data Type: AppConfig — Field: api_call_count (number), reset_date (date) oluştur. Her API çağrısında backend workflow ile sayacı 1 artır. 9.500'e ulaşınca kullanıcıya uyarı göster, 10.000'de API çağrılarını durdur.

⚠️ Önemli: Twitter rate limit resetleme tarihi UTC saat dilimini baz alır. Türkiye saatiyle UTC+3 farkını hesaba kat; aksi halde limit sıfırlanmadan önce çağrıları engellemiş olabilirsin.

Bu yapıyı kurduğunda hem API maliyetlerini kontrol altında tutarsın hem de X platformunun otomasyon politikası ihlallerinden korunursun. Başarılar!
